# VTD — интерактивная модель технического обслуживания

Статическая веб-страница для демонстрационного моделирования периодичности обследований и состава ремонтной программы протяжённого технического объекта.

## Запуск

- GitHub Pages: включить публикацию из ветки `main`, каталог `/`. После публикации страница будет доступна по адресу https://avladova.github.io/VTD/.
- Локально: открыть `index.html` в современном браузере. Сборка, серверная часть и внешние библиотеки не требуются.

## Что моделируется

Пользователь задаёт допустимую вероятность нарушения нормативного условия, множитель скорости изменения состояния, неопределённость диагностики, неоднородность элементов, неопределённость общих параметров объекта, отношение стоимости обследования к стоимости ремонта и ставку дисконтирования.

Для интервалов от 1 до 15 лет моделируются 120 синтетических элементов в 500 сценариях Монте-Карло. Элементы ранжируются по частоте нарушения нормативной границы; ремонтная программа последовательно формируется до выполнения ограничения на вероятность нарушения хотя бы одним оставшимся элементом. Среди рассчитанных планов выбирается план с минимальными приведёнными годовыми затратами.

## Ограничения и данные

Все начальные резервы, скорости изменения состояния и случайные параметры заданы синтетически внутри JavaScript-кода и нужны только для демонстрации интерфейса и вычислительной логики. Они не являются фактическими диагностическими данными и не предназначены для инженерных решений. Ранжирование ремонтных элементов — эвристика, глобальная оптимальность не гарантируется. Модель не учитывает взаимодействие дефектов, появление новых дефектов и последовательность отдельных ремонтов внутри цикла. Для практического применения необходимы калибровка, проверка физико-нормативной функции предельного состояния и независимая валидация на данных конкретного объекта.

В репозитории находятся только страница и краткая инструкция по запуску. Статья, рукопись и исходные диагностические таблицы не включены.
