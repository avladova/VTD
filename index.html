Как читать результат

Для каждого интервала обследования моделируются изменения состояния элементов с учётом индивидуальной неоднородности, общей неопределённости параметров объекта и погрешности диагностических данных. Ремонтируемые элементы исключаются из проверки риска на цикл. Среди допустимых по ограничению ε планов выбирается план с минимальными приведёнными годовыми затратами.

Ограничение: состав ремонтной программы определяется эвристическим ранжированием по частоте нарушений; глобальная оптимальность не гарантируется. Не учитываются взаимодействие дефектов, появление новых дефектов и последовательность отдельных ремонтов внутри цикла. Для инженерного применения необходимы калибровка параметров, проверка нормативной функции предельного состояния и независимая валидация на данных объекта.
